# ============================================================
# 读人：把「字面意思」翻成「底下那层意思」
# ------------------------------------------------------------
# 格式：触发词 | 大概率的意思 | 该怎么接
#   1) 触发词前加 = 表示「整句就得是这个词」，不加就是「句子里出现就算」
#   2) 触发词里可以用 / 分隔多个说法，命中任意一个就生效
#   3) 每轮只挑命中的几条塞给模型，不是整张表都喂
#   4) 改完存盘就生效（按文件修改时间热加载），不用重启
# ------------------------------------------------------------
# 下面是示例，按你们群的说话习惯往上加。
# ============================================================

# ---------- 冷回应：话突然变短，就是有情绪 ----------
=哦 | 不高兴，或者失望，但不想直说 | 别当成「收到」，软一句，或者问「咋了」
=行吧 | 勉强同意，心里还有不服 | 别再解释，见好就收
=你说得对 | 懒得再争了 | 别再解释，换话题

# ---------- 假客气：嘴上说随便，心里有想法 ----------
随便 | 有想法但不想先说 | 给两个具体选项让他挑，别自己拍板
都行 | 有偏好但不想麻烦你 | 直接替他挑一个，说清为什么挑这个

# ---------- 反话：说的和想的是反的 ----------
没事 | 有事，只是不想麻烦你 | 别说「好那就好」，追一句「真没事？」

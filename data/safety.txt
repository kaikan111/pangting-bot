# ------------------------------------------------------------
#  格式：[分类名] action=retort|silent scope=both|group|private
#    action=retort  被套话/说了不该说的 → 按人设怼一句，然后不再继续
#    action=silent  完全不理（一个字都不回）
#    scope=both 群聊私聊都拦 / group 只管群聊 / private 只管私聊
#  分类下面一行一个词；# 开头是注释；re: 开头是正则（高级用法）
#  匹配时大小写、空格、标点、全角半角、叠字都会被忽略
# ------------------------------------------------------------
#  示例表里只留了几个中性词，其余自己往对应分类下面加。
# ============================================================
